<details>
<summary><strong>⚠️ Laboratory safety notes</strong></summary>

- “Quick fix” is a suspicious phrase.
- If it works on the first try, check whether the file was saved.
- A bug that disappears when DevTools opens is plotting something.
- Never deploy on confidence alone. Deploy on testing, too.
- If the fix creates three new bugs, that is called **character development**.

</details>
